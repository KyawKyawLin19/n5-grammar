1. に (Ni) — Time, Destination, Existence

に ကို အချိန်အတိအကျ၊ သွားမယ့်နေရာ၊ တည်ရှိနေတဲ့နေရာနဲ့ လက်ခံသူကို ဖော်ပြတဲ့အခါ သုံးပါတယ်။

UsageJapaneseမြန်မာ
Time7時に起きます。၇ နာရီမှာ အိပ်ရာထတယ်။
Destination学校に行きます。ကျောင်းကို သွားတယ်။
Existence部屋に猫がいます。အခန်းထဲမှာ ကြောင်ရှိတယ်။
Recipient友達にプレゼントをあげます。သူငယ်ချင်းကို လက်ဆောင်ပေးတယ်။

Grammar patterns

Time + に + Verb

6時に起きます。
Roku-ji ni okimasu.
၆ နာရီမှာ အိပ်ရာထတယ်။

Place + に + 行きます / 来ます / 帰ります

日本に行きます。
Nihon ni ikimasu.
ဂျပန်ကို သွားမယ်။
JLPT Trap: 毎日၊ 今日၊ 明日 တို့နောက်မှာ ပုံမှန်အားဖြင့် に မထည့်ပါ။

✅ 毎日勉強します。
❌ 毎日に勉強します。

2. で (De) — Action Place, Method

で ကို Action ဖြစ်ပွားတဲ့နေရာ၊ သယ်ယူပို့ဆောင်ရေးနည်းလမ်း၊ အသုံးပြုတဲ့ကိရိယာတို့အတွက် သုံးပါတယ်။

UsageJapaneseမြန်မာ
Action place図書館で勉強します。စာကြည့်တိုက်မှာ စာလေ့လာတယ်။
Transportationバスで行きます。ဘတ်စ်ကားနဲ့ သွားတယ်။
Tool箸で食べます。တူနဲ့ စားတယ်။
Language日本語で話します。ဂျပန်လို ပြောတယ်။

Grammar patterns

Place + で + Action Verb

レストランで食べます。
Resutoran de tabemasu.
စားသောက်ဆိုင်မှာ စားတယ်။

Transport + で + 行きます

電車で会社に行きます。
Densha de kaisha ni ikimasu.
ရထားနဲ့ ကုမ္ပဏီကို သွားတယ်။

3. に vs で — Key JLPT Difference

にExistence / Destination

တည်ရှိရာ / ဦးတည်ရာ

学校にいます。
Gakkou ni imasu.
ကျောင်းမှာ ရှိတယ်။
でAction Location

လုပ်ဆောင်မှု ဖြစ်တဲ့နေရာ

学校で勉強します。
Gakkou de benkyou shimasu.
ကျောင်းမှာ စာလေ့လာတယ်။
မှတ်ရန်: います / あります နဲ့ တည်နေရာဖော်ပြရင် に၊ 食べます / 勉強します / 働きます စတဲ့ Action ဖြစ်တဲ့နေရာကို ဖော်ပြရင် で သုံးပါတယ်။

4. が (Ga) — Subject, Likes, Ability

が ကို Subject ဖော်ပြဖို့၊ ရှိတယ်ဆိုတာ ပြောဖို့၊ ကြိုက်နှစ်သက်မှုနဲ့ စွမ်းရည်တွေ ဖော်ပြဖို့ သုံးပါတယ်။

UsageJapaneseမြန်မာ
Subject雨が降っています。မိုးရွာနေတယ်။
Existence猫がいます。ကြောင်ရှိတယ်။
Like日本語が好きです。ဂျပန်စာကို ကြိုက်တယ်။
Ability日本語ができます。ဂျပန်စာ တတ်တယ်။
Want水が欲しいです。ရေလိုချင်တယ်။

JLPT patterns to remember

N + が + 好きです ကြိုက်တယ်

N + が + 嫌いです မကြိုက်ဘူး

N + が + 上手です တော်တယ်

N + が + 下手です မတော်ဘူး

N + が + 分かります နားလည်တယ်

私は日本語が分かります。
Watashi wa nihongo ga wakarimasu.
ကျွန်တော် ဂျပန်စာ နားလည်တယ်။

5. を (Wo / O) — Direct Object

を ကို Verb ရဲ့ Object (လုပ်ဆောင်မှုခံရတဲ့အရာ) ကို ဖော်ပြတဲ့အခါ သုံးပါတယ်။ Romaji မှာ wo လို့ ရေးလေ့ရှိပေမယ့် အသံထွက်က o ဖြစ်ပါတယ်။

JapaneseRomajiမြန်မာ
水を飲みます。Mizu o nomimasu.ရေသောက်တယ်။
ご飯を食べます。Gohan o tabemasu.ထမင်းစားတယ်။
本を読みます。Hon o yomimasu.စာအုပ်ဖတ်တယ်။
テレビを見ます。Terebi o mimasu.TV ကြည့်တယ်။
音楽を聞きます。Ongaku o kikimasu.သီချင်းနားထောင်တယ်။

Grammar pattern

Noun + を + Transitive Verb

私はコーヒーを飲みます。
Watashi wa koohii o nomimasu.
ကျွန်တော် ကော်ဖီသောက်တယ်။

が vs を

日本語が好きです。 — ဂျပန်စာကို ကြိုက်တယ်။

日本語を勉強します。 — ဂျပန်စာကို လေ့လာတယ်။

好きです က ကြိုက်နှစ်သက်မှုဖော်ပြတဲ့ expression ဖြစ်ပြီး 勉強します က Action Verb ဖြစ်ပါတယ်။
